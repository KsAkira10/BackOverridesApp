O proxy BackOverrides intercepta requisições de rede e gerencia CORS automaticamente. Escolha o seu gerenciador de pacotes para copiar o comando de inicialização pronto para rodar no terminal do seu projeto:

$
npx @back-overrides/cli
💡 Flags & Opções Úteis do CLI
-p, --port <porta> Define a porta do proxy local (padrão: 8888). A extensão descobre portas automaticamente no range 8888–8908.
-c, --config <arquivo> Caminho para o arquivo JSON de regras (padrão: back-overrides.json).
--remote <url> Sobrescreve a URL base do backend remoto sem alterar o arquivo de regras.
-v, --verbose Habilita logs detalhados de cada requisição interceptada e cabeçalhos CORS no terminal.
back-overrides list Exibe todas as regras ativas configuradas sem iniciar o servidor proxy.
⚙️ Opções do Gerador de Content Script
A extensão só intercepta requisições nestes domínios. Em qualquer outro site, a extensão permanece em Standby.

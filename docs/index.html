Versão 0.1.0 • Produzido para Microfrontends & BFFs

Teste APIs locais mantendo seu frontend 100% apontado para a nuvem.

O BackOverrides intercepta seletivamente endpoints específicos de APIs remotas e os desvia para o seu localhost, resolvendo automaticamente barreiras de CORS, Private Network Access (PNA) e redirecionamentos de página OAuth sem alterar nenhuma linha de código no frontend.

Cenário Corporativo

O Problema de Testar Local com Nuvem

Por que alterar URLs base no frontend quebra seu fluxo de desenvolvimento.

🚫

Bloqueios de CORS e PNA

Quando seu portal roda em HTTPS público (ex.: https://portal.corporate-cloud.io), navegadores modernos bloqueiam chamadas diretas para http://localhost por segurança de Private Network Access.

🔄

Acoplamento de Código

Alterar a URL base de https://api.corporate-cloud.io para http://localhost:8080 exige editar .env, recompilar o frontend e corre o risco de subir URLs locais para produção por engano.

⚡

A Solução BackOverrides

Suas URLs permanecem 100% idênticas às de produção. O BackOverrides intercepta em tempo de execução apenas as rotas declaradas e injeta cabeçalhos CORS permissivos transparentemente.

Instalação

Início Rápido em 30 Segundos

Escolha usar via CLI ou diretamente como biblioteca no seu projeto.

Inicie o proxy reverso apontando para sua API remota e seu backend local:

terminal — bash 
# Executa o proxy sem instalar nada via npx
npx back-overrides \
  --port 8888 \
  --remote https://api.corporate-cloud.io \
  --local http://localhost:8080 \
  --overrides "/bff/core/v1/orders"

Importe o interceptor no ponto de entrada do seu microfrontend ou Single-SPA app:

src/main.ts 
import { setupBackOverrides } from '@back-overrides/client';

setupBackOverrides({
  cliUrl: 'http://localhost:8888',
  autoSync: true // Sincroniza regras automaticamente se você editar o back-overrides.json
});

Carregue a extensão no Chrome para interceptar chamadas fetch e navegações main_frame sem alterar nenhuma linha do projeto:

Passo a Passo 
1. Acesse chrome://extensions/ no Google Chrome ou Edge
2. Ative a opção "Modo do desenvolvedor" no canto superior direito
3. Clique em "Carregar sem compactação" (Load unpacked)
4. Selecione a pasta: packages/extension
Arquitetura Flexível

Os 3 Modos de Operação

O BackOverrides se adapta ao seu ambiente de desenvolvimento.

💻

1. Proxy CLI Inteligente

Proxy reverso Node.js com logs detalhados de requisições, tempo de resposta, headers injetados e tratamento de erros 502 com dicas de diagnóstico.

🌐

2. Interceptor In-Browser

Patch transparente em window.fetch e XMLHttpRequest ou Service Worker. Ideal para Single-SPA e microfrontends carregados via Import Map.

🧩

3. Extensão Chrome (Manifest V3)

Interceptação na camada de rede com chrome.declarativeNetRequest. Suporta requisições assíncronas e redirecionamentos de tela cheia (main_frame) para fluxos de autenticação.

Guias Práticos

Exemplos Reais: Do Básico ao Avançado

Aprenda a aplicar o BackOverrides em diferentes níveis de complexidade.

Nível 1 Sobrescrita de Endpoint REST Simples

Você está criando a rota de criação de usuários localmente (POST /v1/users na porta 3000), mas quer que a listagem (GET /v1/users) continue vindo da API de homologação/nuvem.

back-overrides.json 
{
  "port": 8080,
  "remote": "https://api.corporate-cloud.io",
  "local": "http://localhost:3000",
  "cors": { "enabled": true },
  "overrides": [
    {
      "methods": ["POST"],
      "path": "/v1/users",
      "description": "Apenas POST vai para localhost:3000. GET continua na nuvem."
    }
  ]
}

Nível 2 Parâmetros Dinâmicos e Preservação de Query Strings

Suporte nativo a parâmetros no formato :id ou {id}, além de wildcards (*) preservando perfeitamente query strings (ex.: ?filter=active&sort=desc).

back-overrides.json 
{
  "port": 8080,
  "remote": "https://api.corporate-cloud.io",
  "local": "http://localhost:3000",
  "overrides": [
    {
      "methods": ["GET", "PUT"],
      "path": "/v1/products/:id",
      "description": "Intercepta consultas e updates de produtos específicos"
    },
    {
      "methods": ["*"],
      "path": "/v1/assets/*",
      "description": "Wildcard: tudo em /assets vai para os mocks estáticos do localhost"
    }
  ]
}

Nível 3 Single-SPA Microfrontends com BFF Simulado

No cenário corporativo mais comum, o portal central roda Single-SPA com múltiplos microfrontends. O desenvolvedor edita apenas um MFE apontado via import-map-overrides e quer validar novas rotas de um BFF local:

examples/single-spa-demo/back-overrides.json
{
  "port": 8889,
  "remote": "http://localhost:9001",
  "local": "http://localhost:8080",
  "cors": { "enabled": true, "credentials": true },
  "overrides": [
    {
      "methods": ["POST"],
      "path": "/bff/core/v1/orders",
      "description": "Checkout local v2, enquanto sessão e catálogo permanecem na nuvem"
    }
  ]
}
src/orders-mfe.ts
// O código do microfrontend continua usando a URL corporativa normal:
const res = await fetch('http://localhost:9001/bff/core/v1/orders', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ item: 'srv-101', coupon: 'DEV_V2' })
});

// Com o BackOverrides ativo, esta chamada é desviada em tempo real para o localhost:8080!
const data = await res.json();
console.log('Pedido processado com sucesso:', data.orderId);

Clone o repositório e execute a demonstração do Single-SPA com um comando:

terminal — bash
./examples/single-spa-demo/run-single-spa-demo.sh

Nível 4 Fluxo OAuth 2.0 / SSO Completo com main_frame

Quando uma aplicação inicia o login, ela executa uma navegação de página inteira (window.location.href = .../authorize). Scripts comuns in-browser são bloqueados pelo navegador e não capturam essa mudança.

A Extensão BackOverrides utiliza a API chrome.declarativeNetRequest com o tipo de recurso main_frame habilitado. Ela intercepta a navegação no nível do motor de rede do Chrome e desvia a aba para o seu BFF local, disparando o Identity Provider correto sem que você precise tocar em nenhuma linha do frontend.

packages/extension/background.js — Snippet 
condition: {
  regexFilter: rule.sourceRegex,
  // 'main_frame' garante que cliques em links e window.location.href sejam interceptados!
  resourceTypes: ['main_frame', 'sub_frame', 'xmlhttprequest', 'other'],
}

Referência da API

Esquema do back-overrides.json

Todos os parâmetros disponíveis para customização do proxy e regras.

Propriedade Tipo Padrão Descrição
remote String Obrigatório URL base da API remota oficial (ex.: https://api.corporate-cloud.io).
local String http://localhost:3000 URL base padrão para onde as rotas interceptadas serão encaminhadas.
port Number 8080 Porta local em que o proxy reverso CLI escutará.
cors.enabled Boolean true Injeta cabeçalhos permissivos (Access-Control-Allow-Origin) refletindo a origem solicitante.
cors.credentials Boolean true Permite envio de cookies de sessão corporativos (Access-Control-Allow-Credentials: true).
secure Boolean false Quando false, aceita certificados SSL autoassinados ou corporativos em redes privadas.
overrides Array [] Lista de regras de roteamento (com methods, path, target, passthrough).
Zero Código

Extensão para Google Chrome & Edge

Instale uma vez e intercepte endpoints corporativos sem modificar repositórios de código.

1

Carregar no Navegador

Abra chrome://extensions, ative o Modo do Desenvolvedor e clique em Carregar sem compactação apontando para packages/extension.

2

Sincronização com 1 Clique

A extensão se conecta automaticamente ao BackOverrides CLI (http://localhost:8888) e importa todas as regras do seu back-overrides.json dinamicamente.

3

Suporte a main_frame

Intercepta não apenas fetch e XHR, mas também navegações completas do navegador como o fluxo de login corporativo OAuth/SSO.

# Diretrizes do Projeto e Preferências do Usuário

## Controle de Versão e Git
- **Não comitar nem fazer push automático**: Evite criar commits (`git commit`) ou enviar código para branches remotas (`git push`) a menos que o usuário solicite explicitamente nessa instrução.
- **Desenvolvimento Local**: Mantenha as alterações aplicadas nos arquivos de trabalho locais para que o usuário possa inspecionar, testar e decidir quando e como versionar.
